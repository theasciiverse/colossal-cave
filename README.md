# Colossal Cave Adventure

The original text adventure: explore the cave, gather its treasures, and say the magic word.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install colossal-cave
av play colossal-cave
```

## Credits

Will Crowther wrote Adventure in 1976 and Don Woods expanded it in 1977.
This is their last version, Adventure 2.5 (1995, 430 points), as Eric S.
Raymond's Open Adventure 1.22, released with their permission. Asciiverse
keeps saves out of the install folder and adds a Windows build.
